# My Blog

A simple blog application built with Node.js, Express.js, and EJS.

## Features

- Create blog posts
- View all posts
- Edit posts
- Delete posts
- Responsive design
- Custom 404 page

## Technologies

- Node.js
- Express.js
- EJS
- HTML
- CSS

## How to run

Install the dependencies:

bash

npm install

Start the server:

bash

node index.js

Open this address in your browser:

text

http://localhost:3000

## Note

Posts are stored in memory, so they disappear when the server restarts.
